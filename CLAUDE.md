# Instruções para agentes

- **Antes de qualquer coisa, leia `docs/DIARIO.md`** (decisões, estado atual, próximos passos).
- Ao fim de cada sessão de trabalho, **acrescente uma entrada no topo do diário**: o que foi feito, decisões e o
  porquê, problemas e próximos passos. Atualize `docs/ARQUITETURA.md` se a estrutura mudar.
- Público: brasileiro médio, incluindo quem tem pouca instrução. Linguagem simples, sem clubismo político.
- Toda fonte nova segue `docs/COMO-ADICIONAR-FONTE.md`. Nunca contorne bloqueios de acesso das fontes.
- Verificações: `npm run typecheck`, `npm run ingest -- --list`, `npm run build -w @sb/web`.
