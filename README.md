# Situação do Brasil

Dados públicos oficiais sobre o Brasil, explicados em linguagem simples e **auditáveis até o dado bruto**.

## Rodando
```bash
npm install
npm run ingest        # coleta todas as fontes (cria data/)
npm run api           # http://localhost:3101/api
npm run web           # http://localhost:5173
```
